## 🧑‍💻 About Me
안녕하세요! 현업에서 **SW 개발** 일을 하고 있는 개발자입니다. <b>C++</b>과 <b>C#</b>을 주력으로 다루며, B2B 소프트웨어 제작과 효율적인 시스템 구축에 관심이 많습니다.

퇴근 후 개인 프로젝트로는 주로 **바이브 코딩**으로 게임을 만들고 있습니다. 설치 없이 브라우저에서 바로 플레이할 수 있는 웹 게임 위주이고, 장르는 이것저것 가리지 않고 도전 중입니다.

- 🗡️ **횡스크롤 액션 RPG** : 직업 전직, 보스 패턴, 장비 강화까지 갖춘 2D 액션 RPG
- 🎲 **1인용 테이블탑 RPG** : AI 게임 마스터가 진행을 맡는 주사위 기반 TRPG
- 🐾 **몬스터 수집·육성 RPG** : 200종이 넘는 도감과 맵·데이터 제작 도구까지 직접 만든 수집형 RPG
- 🏰 **모바일 방치형 RPG** : 몬스터 보호소를 운영하며 성장시키는 가벼운 방치형 게임

## 🚀 Main Projects

### 🎮 Game Development
- **Emberwake** 🔥 *(개발 중)* : 빌드 도구나 외부 라이브러리 없이 HTML5 Canvas와 순수 JavaScript로 만든 브라우저 2D 횡스크롤 액션 RPG. 4개 직업과 7차 전직, 13개 지역, 기믹 보스 17종, 장비 강화·잠재능력·펫·퀘스트 시스템을 직접 구현했고, 그래픽과 배경음악도 모두 코드로 생성합니다.
- **pokemon_rl** : 포켓몬 데이터를 활용한 강화학습(Reinforcement Learning) 알고리즘 연구 또는 포켓몬 시스템을 구현한 프로젝트입니다.
- **[TextDungeon](https://github.com/dndjd321/TextDungeon)** : 객체 지향 기반의 캐릭터/몬스터 클래스 구조와 **영구 아이템 강화 시스템**을 구현한 C++ 콘솔 텍스트 RPG 게임.
- **[AvoidTexture](https://github.com/dndjd321/AvoidTexture)** : C++ 기반 콘솔 장애물 회피 아케이드 게임 프로젝트.

### 📈 Finance & Data
- **Real-time Stock Dashboard** : Next.js와 TypeScript, Yahoo Finance API를 활용한 실시간 주식/코인 대시보드 (**막대그래프** 기반 차트 구현).
- **Stock Forecaster** : C# ML.NET 머신러닝을 활용한 주가 등락 예측기.

### ⚙️ Automation & Tools
- **[RoutineAutomator](https://github.com/dndjd321/RoutineAutomator)** : **C++** 기반으로 제작된 루틴 자동화 유틸리티로, 사용자가 사전에 등록한 여러 프로그램들을 일괄적으로 자동 실행하여 빠른 작업 환경 세팅을 돕습니다.
- **WebSafeSpec** : 복잡한 플랫폼별 디자인 규격을 픽셀 단위로 정확하게 변환해 주는 웹 서비스.
